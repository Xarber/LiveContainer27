# App library

The toolbar's Layout and sort menu switches between List and Grid. Both layouts use the same selected sort order. The default shows older installs first, with undated apps first and name and app identity used to resolve ties. Replacing an app preserves its original installation date.

Grid tiles run the app on tap. Touch and hold opens the existing app menu, including settings and container actions. In Grid, use **Move to Folder** to create or select a folder, or **Remove from Folder** to return an app to the main grid. Search shows matching apps across folders. Folder assignments and layout are saved in the app group's preferences. Hidden apps continue to require the existing unlock flow.

A successful install or replacement shows a brief **App installed** checkmark and announces completion to VoiceOver. Cancelling an install or encountering an error does not show the success message.
